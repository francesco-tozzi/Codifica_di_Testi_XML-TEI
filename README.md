# Codifica di Testi in XML-TEI (P5)

Questo repository ospita gli [**esercizi**](https://github.com/francesco-tozzi/Codifica_di_Testi_XML-TEI/tree/main/esercizi) svolti durante il corso e il [**progetto finale**](https://github.com/francesco-tozzi/Codifica_di_Testi_XML-TEI/tree/main/progetto_CdT_Tozzi_Francesco) realizzato per l'esame di **Codifica di Testi** presso l'**Università di Pisa**. Il lavoro consiste nella codifica digitale in formato **XML-TEI (P5)**. In particolare, il progetto finale è una selezione di estratti della rivista di fine Ottocento *"La Rassegna settimanale di politica, scienze, lettere ed arti"* (Casa editrice Barbera, Roma).
