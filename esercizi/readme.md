# Esercizi del corso

Questo repository ospita degli esercizi base svolti per il corso di **Codifica di Testi** presso l'**Università di Pisa**. 
Gli esercizi sono di graduale difficoltà: si parte dai concetti base del markup con xml all'uso dei tag dello standard TEI.
